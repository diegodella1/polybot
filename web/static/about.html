About this experiment

Polybot is an experimental automated trading bot for Polymarket's BTC Up/Down 5-minute binary markets. It was built as a learning project to explore algorithmic trading, signal processing, and market microstructure in a live environment.

What it does

Every 10 seconds, the bot analyzes multiple data sources to decide whether to trade:

  • BTC Momentum — Real-time price action from Binance klines
  • Orderbook Skew — Buy/sell pressure imbalance on Polymarket
  • Fair Value — Mispricing detection between BTC movement and market odds
  • Pattern Matching (RAG) — k-NN similarity search over historical trade outcomes
  • Sentiment — News analysis via LLM (GPT-4o-mini)

Why it exists

This is not about making money. The bankroll is intentionally small (~$15 USDC) and the primary goal is learning: how signals interact, how markets behave at the microstructure level, how to build robust automated systems, and how to iterate on strategy through data.

The bot is constantly evolving — signals get tuned, risk rules get adjusted, new components get added. Every trade generates data that feeds back into the system (RAG patterns). It's a live experiment in the truest sense.

How it's built

  • Python 3.11 + asyncio, FastAPI, SQLite
  • Runs on a Raspberry Pi 5 as a systemd service
  • Real-time data via Binance and Polymarket WebSockets
  • On-chain execution via py-clob-client (Polygon)
  • Dashboard you're looking at: vanilla HTML/JS, no framework
